Google Sheets

Cómo configurar Google Sheets

  1. Creá una nueva planilla en Google Sheets
  2. Creá 4 hojas: Productos, Usuarios, Pedidos, Config
  3. Andá a Extensiones → Apps Script
  4. Pegá el código del archivo google-apps-script.js
  5. Desplegá como aplicación web (ejecutar como: yo, acceso: todos)
  6. Copiá la URL y pegala arriba
